# 30 Pro Brushes for Photoshop & Illustrator

> **Created by Abdullah**

A professional web studio and suite of 30 graphic design brushes for Adobe Photoshop and Adobe Illustrator, featuring real-time drawing canvas testing and single/bundle export engines.

## 🚀 Live GitHub Pages Deployment

This repository is configured with an automated GitHub Actions deployment workflow (`.github/workflows/deploy.yml`).

### How to enable GitHub Pages:
1. Push this repository to your GitHub account.
2. In your GitHub repository, navigate to **Settings** > **Pages**.
3. Under **Build and deployment** > **Source**, choose **GitHub Actions**.
4. Whenever you push to `main` (or trigger **Deploy to GitHub Pages** under the **Actions** tab), GitHub will automatically build and publish your site to `https://<username>.github.io/<repository-name>/`.

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

## ✨ Features
- **30 Calibrated Brushes**: Inking, Textures, Painting, Shading/Halftones, and FX (including Real-View Moon).
- **Interactive Drawing Studio**: Pressure dynamics, streamline smoothing, canvas backgrounds (Dark, Light, Parchment, Blueprint, Transparent Grid).
- **Adobe Photoshop Export**: 2048px PNG alpha stamps + ExtendScript (.jsx) auto-import script.
- **Adobe Illustrator Export**: Art/Scatter/Pattern vector SVG brush definitions.
- **ZIP Suite Packaging**: Download the entire 30-brush toolkit with 1 click.
